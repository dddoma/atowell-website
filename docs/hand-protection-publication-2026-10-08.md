## 독립 페이지와 환자 안내 문구 복사

- 사용자 승인에 따라 손 보호 본문을 `/medical/dermatology/hand-protection`으로 분리합니다. 내용은 기존 게시본을 유지하고 참고문헌 번호를 새 페이지에 맞춥니다.
- 피부염·습진 페이지에는 강조 카드와 ‘손 보호 방법 바로 보기’, ‘링크 복사’ 버튼을 나란히 둡니다. 이전 `#hand-protection` 링크는 이 카드로 이어집니다.
- ‘링크 복사’는 채팅에서 승인된 환자 안내 문구 전체(새 페이지 주소, 세 가지 실천 수칙, 의원명·전화번호)를 복사합니다. BMI 상담 결과 복사와 같이 성공 상태를 표시하며 실패 시 수동 복사 문구를 제공합니다.
- 복사 문구는 `data/handProtectionMessage.ts`, 독립 안내 내용은 `data/handProtectionArticle.ts`에서 관리합니다.
- 새 페이지 최초 게시·수정·근거 확인일은 2026-10-08입니다. 배포 승인과 의학적 검토는 구분하여 기존 페이지와 새 안내의 검토 대기 상태를 유지합니다.
- 사용자가 구현 후 운영 배포까지 다시 승인했고 웹에서 확인하겠다고 밝혔습니다. 배포 전 빌드·기존 회귀 검증, 배포 후 실제 페이지 이동·클립보드 복사를 확인합니다.
