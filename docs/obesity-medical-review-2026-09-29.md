# 비만·체중관리 의료정보 — 원장 검토용

## 범위
기존 5개 준비 중 항목을 개별 URL의 답변 페이지로 작성했습니다.
- /medical/obesity/diagnosis
- /medical/obesity/goals
- /medical/obesity/medication
- /medical/obesity/side-effects
- /medical/obesity/plateau

기존 마운자로 상담 슬라이드, 약품 가격, 진료예약, 피부질환 의료정보 내용은 변경하지 않습니다.

## 공개 안전장치
- 모든 신규 글은 `review.status: draft`입니다.
- Vercel Preview 또는 로컬 개발 환경에서만 초안을 읽을 수 있습니다.
- Production에서는 미승인 상세 URL이 404이며, 목록은 준비 중으로 표시됩니다.
- 초안에는 noindex/nofollow를 적용하고, sitemap과 MedicalWebPage 검토자·게시일 JSON-LD에서 제외합니다.
- 원장 검토 완료 문구와 최초 게시 날짜를 미리 기입하지 않았습니다.
- main 병합 또는 Production 배포는 승인 후 별도 작업입니다.

## 임상 검토 포인트
1. 한국 성인 비만 진단(BMI 25 이상)과 개별 약물의 체중관리 허가 대상(BMI 30 이상 또는 27 이상~30 미만+동반질환)을 구분했습니다.
2. 초기 5~10%/약 6개월 목표는 시작점이며 필수 속도·최종 상한이 아니라고 명시했습니다.
3. 마운자로 국내 허가 원문은 한국릴리 공식 페이지에서 연결된 식약처 캐시 원문을 확인했습니다. 위고비 국내 품목 원문은 도구 접근이 되지 않아 EMA/MedlinePlus/제조사 자료로 보완했고, 해당 두 글의 검토 안내에 국내 원문 최종 대조 필요성을 명시했습니다. 해외 추가 적응증이나 경구·고용량 제형을 국내에 적용하지 않습니다.
4. 모든 갑상선암을 일괄 금기로 쓰지 않고 갑상선 수질암/MEN2 병력을 알리도록 안내했습니다. 국내 품목별 금기·경고와 최종 대조합니다.
5. 약의 시작·유지 용량 차이, 임의 병용/증량/간격 변경 금지, 임신·수유, 마운자로 경구 피임약 보완(시작 및 증량 후 각각 4주), 마취·진정 전 알림을 포함했습니다.
6. 심한 알레르기·의식 변화는 119/응급실, 지속성 심한 복통·탈수·폐색 의심 증상·급성 시력 변화는 즉시 평가로 분리했습니다. 아토웰의 실제 상담 연락 흐름과 문구를 최종 확인합니다.
7. 정체기는 의지 부족이나 자동 증량 사유로 설명하지 않았습니다.

## 승인 후 공개 방법
각 글의 `data/obesityArticles.ts` review 객체를 아래와 같이 바꿉니다. 날짜는 실제 승인/공개일을 사용합니다.
```
review: {
  status: "published",
  publishedAt: "실제 최초 공개일 YYYY-MM-DD",
  modifiedAt: "실제 최종 수정일 YYYY-MM-DD",
  reviewedAt: "실제 의학적 검토일 YYYY-MM-DD",
  reviewerName: "권병현"
}
```
승인 전에 남은 원문 대조와 문구 수정을 마칩니다. 공개된 글만 sitemap, 게시일, 의학적 검토자 JSON-LD에 자동 반영됩니다. 승인하지 않은 글은 계속 비공개로 둘 수 있습니다.
