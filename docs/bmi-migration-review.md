# BMI 슬라이더 이전 검토

## 범위
- 기존 BMI 슬라이더를 동일 홈페이지의 `/tools/bmi` 경로로 이전
- 비만치료 페이지의 기존 버튼 목적지만 `/tools/bmi`로 변경 (새 탭 열기 유지)
- 기존 의원 헤더와 푸터 안에서 계산기 자체의 화면·색상·입력·결과를 유지
- 원본: https://bmi-slider-x20.ddomadoc.chatgpt.site/ 의 게시 버전 8, 소스 커밋 `31b3463fa476f49b54ce8a9bd51752fd3b500ad5`
- 원본 사이트 연결, iframe, 별도 계산 API에 의존하지 않음. 입력값은 React 상태에만 존재하고 별도로 전송·저장하지 않음

## 보존한 동작
- 초기값: 키 170cm, 현재 65kg, 목표 58kg
- 키 140–200cm / 체중 40–160kg, 정수 슬라이더·±버튼·정수 선택
- 키에 따른 목표 BMI 바로 선택 범위와 가장 가까운 정수 kg 반올림
- 현재/목표 BMI, 감량/증량, 그래프, 정상 체중 범위와 결과 복사 문구
- 원본의 BMI 구간 20/25/30과 안내 문구를 그대로 유지. 이 이전 작업은 의료 기준 재검토가 아님
- 화면의 정상 체중 범위 상한 표시는 원본과 동일하며, 복사 문구는 상한 ‘미만’으로 표시

## 통합에 필요한 변경
- Tailwind의 슬라이더 스타일을 해당 계산기 전용 CSS Module로 옮겨 다른 페이지와 충돌하지 않도록 분리
- 원본과 같은 Base UI 1.7.0, Lucide 1.31.0 사용
- 슬라이더의 접근성 이름과 키보드 포커스 표시 보완
- 복사 권한이 거부된 경우 오류 안내 및 타이머 정리 추가
- 키 변경 시 화면 아래의 목표 BMI 숫자를 `scrollIntoView`로 찾아가던 동작을 수정. 각 숫자 목록 내부에서만 가로 위치를 조절하여 페이지의 세로 스크롤을 유지

## 경로 변경 (2026-10-01)
- 계산기의 현재 주소는 `/tools/bmi`이며 이전 `/bmi` 주소는 HTTP 308로 영구 이동
- 비만치료 버튼과 canonical URL은 새 주소를 직접 사용
- 계산기 UI, 계산식, 가로 스크롤 수정은 변경하지 않음
