# 환자 안내문 링크 복사 원칙

2026-10-12 원장 요청에 따라 적용하며, 2026-10-13 버튼 위치 변경 요청을 반영합니다.

- ‘링크 복사’는 주소만이 아니라 환자 문자로 보낼 안내문 전체를 복사합니다.
- 형식: `[안내문 제목]` → 짧은 안내 → 자료 이름과 운영 주소 → ‘꼭 기억해 주세요.’와 핵심 수칙 → 의원명·전화번호.
- 문자에 붙여넣기 쉽도록 줄바꿈을 유지하고 수칙 앞에는 `-`를 사용합니다.
- 공유 주소는 미리보기 주소가 아닌 `https://atowell.kr`의 해당 페이지 주소입니다.
- 손 보호·얼굴 지루성피부염·아토피피부염 관리·대상포진 진료 후 안내문에서는 제목 영역의 우측 상단에 ‘링크 복사’를 배치합니다. 하단에는 복사 버튼을 중복 배치하지 않습니다. 모바일에서도 오른쪽 정렬을 유지합니다.
- 복사 성공을 표시하고, 자동 복사가 실패하면 같은 문구를 직접 선택해 복사할 수 있게 제공합니다.
- 같은 안내문의 문구는 공통 데이터로 관리하여 소개 카드와 상세 페이지에서 동일하게 복사합니다.
- 새로운 안내문도 이 형식을 따르되, 의료 문구의 검토·공개 절차는 기존 원칙을 따릅니다.

현재 적용: 손 보호, 얼굴 지루성피부염, 아토피피부염 관리, 대상포진 진료 후 안내문. 기존 안내 카드도 안내 문구 전체 복사 방식을 유지합니다.
