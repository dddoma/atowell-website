# 위고비 주사법 안내 — 원장 검토 대기

국내 다회용 펜 전용. 한국 노보 노디스크 공식 영상 페이지, 제품정보와 식약처 허가사항을 확인. 펜 조작은 제조사 FlexTouch 영국 환자용 설명서를 보조 근거로 사용했으며 해외 적응증·고용량 요법은 적용하지 않음. 영상 페이지 연결만 확인했으며 영상 전체 재생 검증은 하지 않음. 다운로드·재배포하지 않고 원본으로 연결.

- 매번 새 바늘, 새 펜 첫 사용 시 흐름 확인, 처방량을 표시창으로 설정, 0 이후 누른 채 천천히 6까지 세기.
- 국내 누락 기준 5일, 요일 변경 72시간 초과, 개봉 후 6주·30℃ 이하 또는 냉장. 누락 보충과 요일 변경 규칙을 혼합하지 않음.
- /clinic/wegovy에는 FAQ가 없어 가격 아래, 처방 전 확인 섹션 앞에 안내 링크·복사 아이콘 배치.
- Preview/development에서만 접근. production 페이지 404·진입 링크 숨김·sitemap 제외.
- 승인 후 공개 플래그, 실제 검토·게시일, sitemap 항목과 관련 경로 수정일 반영 필요.

사용자 후속 요청으로 체중관리 링크, 6개 주제·18문항 FAQ와 FAQ별 복사 버튼 추가. 주사법 바로가기는 새 FAQ 바로 위에 배치. FAQ도 공개 플래그 false이며 운영 경로·사이트맵 제외. 생활관리 근거는 NIDDK 자료. 승인 시 두 공개 플래그와 각 하단 검토·게시일, FAQ 구조화 데이터, sitemap·수정일 반영 필요.
